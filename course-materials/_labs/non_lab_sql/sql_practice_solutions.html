In this bit of livecoding we’ll be focused on bringing SQL queries into Rstudio using the DBI and RSQLite packages.

We’ll have to write the queries in SQL as we are communicating with the database. (You can use packages like dbplyr to use tidyverse functions to query databases, but we haven’t got time for that.)

We’ll start with the Netflix database.

Setup

library(DBI)

These are times, in milliseconds, since Jan 1, 1970. This is a fairly common way of keeping time. This is called the “unixepoch.”

Convert those times

We can use date() or datetime() to convert them. We first divide by 1000 to get them into seconds.

dbGetQuery(
    mydb, 
    "SELECT date(start_date/1000, 'unixepoch') AS start_time
    FROM view_summary
    LIMIT 10"
